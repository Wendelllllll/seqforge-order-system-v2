# SeqForge 网站测试勾选清单

初版日期：2026-10-23；功能与验证范围更新：2026-11-01。依据当前源码、邮件说明、隔离测试及 AWS 部署记录。**这是测试计划，所有项目默认未测试，不能当作整站已通过报告。**

本次修正标准 Oligo 估价、结果先私有上传再明确发布、结果通知、密码恢复，并补充 Dropbox 和异常订单检查。既有条目 ID 保持不变；从旧版导入的通过记录必须按更新后的预期复核。第 27 组分别记录历史清单、11 月 1 日自动化证据与 AWS 实测范围，不自动给任何条目打勾。

配套 `TEST_CHECKLIST_ZH.html` 可直接用浏览器打开，勾选通过、记录失败/阻塞/不适用及备注，并导入/导出进度。进度保存在当前浏览器，换设备或清理浏览器前先导出 JSON。此 Markdown 是便于编辑、打印和版本管理的原始清单。

## 使用方式与当前功能边界

先完成第 01–04 组主流程，再按模块补测。P0＝订单、价格、权限、数据或交付的核心检查；P1＝重要业务和异常检查；P2＝体验与兼容性。勾选只表示**实测通过**；失败、阻塞、不适用分别记录，不能用勾选表示“看过了”。

每轮记录：执行人、日期、代码版本/未提交改动、环境地址、数据库测试 schema、浏览器/设备、测试账号、全局/客户价格版本、邮件模式、结果文件名和校验值。失败记录：条目 ID、前置条件、实际步骤、预期/实际、订单号、时间、截图/日志、严重程度、修复版本、复测结果。不要把密码、SMTP 密钥、验证 token 或真实客户资料写进记录。

| 服务/环节 | 当前代码范围 | 本轮验收终点 |
| --- | --- | --- |
| Sanger | Standard / Pre-mixed；Tubes / Plate；提交、管理、上传、下载 | 客户登录自己的账号，下载并打开正确的结果文件 |
| Whole Plasmid | Tubes / Plate；≤12,000 bp 与 >12,000 bp 分档 | 同上，并核对长度分档与每个样本的结果 |
| Oligo | Standard / Modified；标准规格 $0.25/base 估价，其他规格另报价；保存申请与规格 | 估价不等于最终批准。报价录入/客户批准/生产/物流/最终交付尚未实现 |
| 邮件 | 客户验证、订单确认、结果就绪、异常/恢复、密码重置；内部新客户/新订单提醒 | 队列行为与每种邮件的真实邮箱收件分别验收 |
| 暂未实现邮件 | 普通进度变化、改价、结果替换/撤回通知 | 结果首次发布与异常/恢复已有通知，不等于所有状态变化都发邮件 |
| Dropbox / 异常单 | 公共地点地图、下单选择、管理员地点维护；On hold 原因、恢复与历史 | 地址快照、权限、版本冲突、客户提示与邮件分别验收 |
| 支付与履约 | Invoice / Purchase order 信息记录，收件/取件说明 | 目前不扣款、不自动开发票、不自动预约取件 |

**环境约束：**用户的 `localhost:3000` 是工作环境，不能提交假订单、改工作价格、替换真实结果或发送测试邮件。订单自动化使用 `npm run test:smoke`；人工提交也必须由工程侧准备独立端口、独立 PostgreSQL schema、独立结果目录的隔离环境。当前 smoke 自动结束并清理，不是已提供的长期人工测试服务器；不要绕过 direct smoke guard。真实邮箱投递需另外准备同等数据隔离、只发往指定测试邮箱的受控环境，不能解禁 smoke 的 SMTP 禁用保护。

**AWS 测试站：**`https://seqforgebio.com` 已于 2026-11-01 部署，使用独立私有数据库和结果目录；旧网站 `seqforge.com` 与公司邮箱托管保持原样。该站用于获授权用户的实际试用，不能把“测试站”理解成允许向其客户队列灌入合成订单。破坏性、改价、并发及合成订单检查仍在隔离环境执行；云站真实邮件已启用，须核对收件范围。

**价格基准：**下表只适用于未改初始价、未设客户专属价的隔离环境。实际测试先记录该环境生效价格，再独立手算；不得把默认价当作你工作数据库现价。

| 场景 | 初始单价/算例 |
| --- | --- |
| Sanger Standard Tubes / Plate | $5.50 / $4.50 每反应；2 个样本分别 2、1 个引物＝3 个反应；管装 $16.50 |
| Sanger Pre-mixed Tubes / Plate | $4.50 / $3.50 每反应；96 孔满板＝$336；3 孔＝$10.50 |
| Whole Plasmid Tubes / Plate | ≤12,000 bp 每样本 $5；>12,000 bp 每样本 $15；12,000+12,001 bp＝$20 |
| Whole Plasmid 未知长度 | 基础档暂估，明确待实验室确认；不等同已确认最终价格 |
| Oligo 标准规格 | 25 nmol、Desalted、无修饰：$0.25/base；20 + 24 bases＝$11 标准合成估价；税、运费、交付形态及最终规格待确认 |
| Oligo 其他规格 / 混合申请 | 其他规模、纯化、修饰另报价；混合申请只显示已知标准小计，总额仍待报价，不能把未知部分当免费 |

最低组合矩阵：Sanger 2 种模式×2 种容器，共 4 种组合各跑一次；Whole Plasmid 两种容器各跑已知长度混合单与未知长度单；Oligo Standard、Modified 各跑一次申请。录入方式交叉覆盖手填、Excel 单元格粘贴、CSV/TSV 导入；账号覆盖游客转登录、新注册未验证、普通价客户 A、专属价客户 B、同实验室不同账号 C、管理员 D。不要把所有维度做无意义的全排列，先保证每项关键业务规则至少有正反两个案例。
